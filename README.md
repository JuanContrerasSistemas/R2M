# R2M
Recommendation to Market es una plataforma de recomendaciones inteligentes orientada al sector del comercio electrónico de moda. Su propósito es permitir que empresas medianas mejoren la personalización de la experiencia de compra mediante técnicas de Machine Learning y una administración transparente de estrategias de recomendación.
